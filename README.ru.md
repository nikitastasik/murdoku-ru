# Murdoku — русская версия

Форк [Murdoku](https://github.com/LifeValuable/murdoku) (оригинальная идея — Manuel Garand,
эта фан-версия — Dirk Aporius / TheApo, лицензия MIT) с полным русским переводом:
интерфейс, показания подозреваемых, подсказки решателя, обучение, редактор, генератор
и названия всех 145 дел.

Язык переключается кнопкой **DE / EN / RU** на стартовом экране и в настройках (шестерёнка).
При первом запуске он выбирается по языку браузера, дальше запоминается.

---

## Ярлык на Mac: клик — и игра открылась в браузере

Один раз создаём ярлык:

```bash
cd ~/PycharmProjects/murdoku-ru && bash scripts/make-mac-launcher.sh
```

Появится **`~/Applications/Murdoku RU.app`** с иконкой игры. Дальше:

- двойной клик — игра открывается новой вкладкой в браузере по умолчанию;
- ярлык удобно перетащить в Dock или на рабочий стол (⌥⌘-перетаскивание сделает алиас);
- приложение находится через Spotlight (⌘Space → «Murdoku»).

Что происходит по клику:

1. если локальный сервер уже поднят — просто открывается новая вкладка (≈0,3 секунды);
2. если нет — при необходимости ставятся зависимости и пересобирается проект
   (только когда исходники новее сборки), поднимается сервер на `http://localhost:4173`
   и открывается браузер. Первый запуск занимает несколько секунд;
3. **когда закрывается последняя вкладка с игрой, сервер сам завершается** — секунд
   через 15. Ничего вручную выключать не нужно, фоновых процессов не остаётся.

Как это работает: игру отдаёт маленький сервер [`scripts/serve-game.mjs`](scripts/serve-game.mjs)
(только `localhost`, без зависимостей). Страница держит с ним открытое соединение —
пока вкладка жива, живо и оно; вкладку закрыли — соединение обрывается, и сервер выходит.
Перезагрузка страницы (⌘R) сервер не роняет, несколько вкладок тоже поддерживаются:
он ждёт, когда закроется последняя. Если браузер вообще не открылся, сервер снимается
сам через полторы минуты.

Адрес `localhost:4173` работает только пока запущен сервер, поэтому закладку на него
делать не стоит — игру всегда открывает ярлык.

Логи запуска: `/tmp/murdoku-ru.log`. Ошибки показываются системным алертом.

Свои имя ярлыка и порт:

```bash
bash scripts/make-mac-launcher.sh "Мурдоку"
MURDOKU_PORT=5000 bash scripts/start-game.sh
```

Ярлык помнит путь к проекту — если папку переместить или переименовать,
пересоздайте его той же командой.

## Запуск без ярлыка

```bash
npm install        # один раз
npm run dev        # режим разработки: http://localhost:5173
npm run build      # сборка в dist/
npm run preview    # отдать собранное средствами vite (не выключается сам)
```

Тот же сервер, что и у ярлыка (сам выходит после закрытия вкладки):

```bash
node scripts/serve-game.mjs   # http://localhost:4173
```

Проверки: `npm run typecheck`, `npm run lint`, `npm test`.

## Как устроен русский перевод

Все строки лежат в [`src/i18n/locales/ru.json`](src/i18n/locales/ru.json) — в коде текста нет.
Русская грамматика потребовала нескольких словарей, которых нет у немецкого и английского
(рендерер [`src/i18n/Renderer.ts`](src/i18n/Renderer.ts) подхватывает их только если они есть,
поэтому de/en работают как раньше):

| Что | Где | Пример |
| --- | --- | --- |
| Падежи объектов | `object` (род.), `objectPrep`, `objectInstr`, `objectNom`, `objectSame`, `objectEvery` | «возле стола», «на столе», «под зонтом» |
| Комнаты с предлогом | `roomIn.*` | «Гостиная» → «в гостиной», «Кухня» → «на кухне» |
| Род глагола | `pron.*` («он был» / «она была»), `copula.*` для показаний от имени | «Bella была у окна» |
| Числительные | `langTag: "ru"` + формы `_one` / `_few` / `_many` | «1 клетка / 2 клетки / 5 клеток» |

Названия дел переведены в самих уровнях: `titles.ru` в `levels/*.json`.

## Обновление из оригинального репозитория

```bash
git fetch upstream
git merge upstream/main
```

Конфликты будут в основном в `src/i18n/locales/*.json` и `levels/*.json`
(там добавлены ключ `ru` и русские названия).
